# 2235. Add Two Integers

**Difficulty:** Easy

## Problem Summary

Given two integers, return their sum.

## Examples

```text
Input: num1 = 12, num2 = 5
Output: 17

Input: num1 = -10, num2 = 4
Output: -6
```

## Approach

This problem is a straightforward introduction to writing functions in Python. Simply return the sum of the two input integers using the `+` operator.

## Complexity

* **Time:** O(1)
* **Space:** O(1)

## Concepts Practiced

* Functions
* Integer arithmetic
* Returning values
* Python syntax

## Notes

A simple warm-up problem to become familiar with LeetCode's function format and Python syntax.
